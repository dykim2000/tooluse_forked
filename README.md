# neat-tooluse
Simple tool use using the neuroevolution algorithm NEAT.

## Publication

Qinbo Li, Jaewook Yoo, and Yoonsuck Choe. Emergence of tool use in an articulated limb controlled by evolved neural circuits. In Proceedings of the International Joint Conference on Neural Networks, 2015. DOI: 10.1109/IJCNN.2015.7280564.

   http://faculty.cs.tamu.edu/choe/ftp/publications/li-ijcnn15.pdf

## Files

1. anji_2_01 : contains original ANJI code and simple navigation demo
   (navigation code: Yoonsuck Choe)
  * Try this: `./navi_evaluate.sh navi.properties 13785`
2. neat-tooluse : contains tool use and reaching code 
   (tool use code: Qinbo Li)
  * NOTE: This directory contains the main tool-use code
3. README.md : this file
